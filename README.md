# Biological Data Analysis and Visualisation Using R

**Author:** Ochai Moses Ameh

## Project Overview

This project demonstrates the use of R for analysing and
visualising illustrative biological data.

The dataset contains plant height and chlorophyll measurements
under three treatment conditions: control, moderate stress,
and severe stress.

## Objectives

- Organise and inspect biological data.
- Calculate descriptive statistics.
- Compare measurements across treatment groups.
- Examine the correlation between plant height and chlorophyll.
- Use analysis of variance (ANOVA) to compare plant heights.
- Visualise plant height using a boxplot.

## Files

- `analysis.R`: R script for data analysis.
- `plant_growth.csv`: Illustrative plant growth dataset.

## Tools Used

- R programming language
- Descriptive statistics
- Correlation analysis
- Analysis of variance (ANOVA)
- Data visualisation

## Important Note

The dataset is illustrative and was created for learning
and demonstration purposes. It does not represent actual
experimental measurements.
